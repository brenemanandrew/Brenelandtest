# Meshy - everything in one place

Each block below is a complete prompt. Copy the whole grey box into Meshy. Nothing else needed.

## Settings (same for every asset)
- Mode: Text to 3D (or Image to 3D from a crop of `reference/concept-sheet.png` if the object is on it).
- Topology: triangles, low poly. Remesh to the asset's triangle target.
- Texture: base colour only. Size listed per asset.
- Pose: upright, standing on the ground, front facing the camera.
- Export: GLB. Name it as listed and upload it in the chat.

## Checks before you accept a model
1. Reads clearly from far away.
2. No more than 4 main colours.
3. Near the triangle target.
4. Looks at home next to the concept sheet.
