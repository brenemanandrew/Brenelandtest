# Strip mall and game store audit (from breneland-live/js, read 2026-11-14)

Bottom line: the strip mall (Summit Slice pizza + Peak Threads clothes; there is NO music store, music-place.js only picks background music) is a loaded Blender model models/strip-mall.json with parts `shell` (5,860 tris) and `inside` (45,214 tris) plus ~50 anchors, built from strip-mall-plan numbers, with a code fallback. The game store (Breneland Games & Hobbies) has NO model: everything is code (game-store-build.js).

What happens: game store has hours, swinging front doors, game boxes that launch games, a demo table (Bookwyrm playtest days, cat tail), 23 seats with seated cameras, Clem and customers, a leaderboard in the east window, the D&D back room (dnd.js) with its own doors, a free-to-borrow shelf, a portal cull that hides the town from inside. Summit Slice: hours, bell door, 20 seats, staff Zoe and Asha, party nights (blinds, UV, light truss), Pete's deliveries. Peak Threads: weekly stock on racks/counter (try on, buy with fish, server-checked), fitting-room mirror camera, 4 dressed mannequins, staff Belinda and Mina; the bus stops at its door.

May change: materials, colours, siding, trim, footing, parapet styling, decorative windows, rooftop gear, back/side decoration, canopy styling (same posts and underside), the game store's brick, awning, trim, roof props, meeple.
